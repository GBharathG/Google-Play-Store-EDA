# Google Play Store Analysis – Python

## Project Overview

This project performs an exploratory data analysis of Google Play Store application data using Python. The analysis focuses on understanding app categories, ratings, reviews, installs, pricing, and other characteristics of applications available on the Google Play Store.

## Objective

The objective is to explore app data, identify important patterns and relationships, and generate insights into application popularity, user engagement, ratings, categories, and pricing.

## Dataset

The dataset contains information about Google Play Store applications, including app name, category, rating, reviews, number of installs, app type, price, content rating, and other application attributes.

## Analysis Performed

- Dataset exploration
- Data quality assessment
- Missing-value analysis
- Data cleaning and preprocessing
- Descriptive statistics
- App category analysis
- Rating analysis
- Install analysis
- Review analysis
- Free vs paid app analysis
- Distribution and relationship analysis
- Business insights

## Tools & Technologies

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Workflow

1. Load and understand the dataset
2. Examine data structure and data types
3. Identify and handle data quality issues
4. Clean and preprocess the data
5. Perform exploratory data analysis
6. Analyze ratings, reviews, installs, categories, and pricing
7. Visualize important patterns
8. Generate key insights

## Key Areas of Analysis

- App categories
- User ratings
- Number of reviews
- App installs
- Free vs paid applications
- App pricing
- Content ratings
- Application popularity and engagement

## Files

- `.ipynb` – Complete Google Colab notebook containing the analysis
- Dataset – Source data used for the analysis

## Conclusion

The analysis provides a data-driven understanding of Google Play Store applications and highlights patterns in app categories, ratings, installs, reviews, and pricing using Python-based exploratory data analysis techniques.
